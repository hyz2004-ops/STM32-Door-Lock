## 目录内容

| 文件 | 作用 |
|---|---|
| `index.html` | 看板页面（双击打开，六张统计卡 + 实时事件流 + 远程开锁） |
| `mqtt.min.js` | MQTT 客户端库（index.html 依赖，须同目录） |
| `mosquitto.conf` | 代理配置（1883 TCP + 9001 WebSocket，匿名） |
| `start-dashboard.bat` | 一键启动：起代理（若没起）+ 显示本机 IP + 打开看板 |
| `stop-dashboard.bat` | 停止代理 |
| `test-broker.js` | 连通性自测脚本：`node test-broker.js`，全部通过显示 ✅ |
| `mosquitto-2.1.2-install-windows-x64.exe` | 安装包备份（已装好，可留可删） |

## 日常使用

1. 电脑插网线、开移动热点（设置 → 网络和 Internet → 移动热点，SSID `doorlock`）
2. 双击 `start-dashboard.bat` —— 自动启动代理、打开看板
3. 看板左上角变绿点即连上，刷一下卡试试

> **代理已设为开机自启**（启动文件夹里的 `智能门锁MQTT代理.lnk`，登录后后台自动运行）。
> 想取消：按 `Win+R` 输入 `shell:startup`，删掉该快捷方式即可。
> 注意：移动热点本身 Windows 不会记住开启，每次开机后在设置里点一下热点开关。

## 排查

- 看板红点：代理没跑 → 双击 `start-dashboard.bat`；或运行 `node test-broker.js` 定位
- 门锁连不上：确认门锁和电脑在同一热点、固件 IP 是电脑当前 IP、防火墙已放行 1883
- 端口被占：`taskkill /F /IM mosquitto.exe` 后重新启动
